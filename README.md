Lantern Duel is an original three-suit card game played in a browser from static files. Spend four points of light per turn, read the rival's telegraphed flame, and combine Amber ▲, Tide ● and Moss ◆ for resonance, prism and exploit bonuses.

## Run it

```sh
node serve.ts
# open http://localhost:8080
```

To assemble the entry locally: `mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts`.
